# Notebook output extraction

These files were extracted verbatim from `takehome_final.ipynb`.

The Colab VM reset caused some standalone intermediate files to be lost. The executed
cell outputs, timestamps, hashes, warnings and diagnostics remained saved in the notebook.
This directory makes those preserved outputs searchable without claiming that they are the
original standalone log files.

- `INDEX.txt`: maps extracted files to the first line of each source cell.
- `KEY_EVIDENCE.txt`: quick index of cells containing major evidence used in the report.
- `cell_*.txt`: source code plus displayed output for each code cell with saved outputs.
